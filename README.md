# Projeto Desenvolvimento Web

## Visão geral

Este projeto é uma landing page institucional para a empresa fictícia Astra, desenvolvida com HTML, CSS e JavaScript. O site simula uma plataforma digital voltada para tecnologia, serviços de TI e gestão de solicitações de clientes.

A aplicação inclui páginas de:

- apresentação institucional;
- login do cliente;
- cadastro de usuário;
- troca de senha;
- solicitação de serviços;
- visualização de pedidos e acompanhamento.

## Objetivo

O objetivo principal foi criar uma interface moderna e responsiva, com foco em experiência do usuário, identidade visual e validação de formulário no front-end.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage para persistência local de login e solicitações

## Funcionalidades

- Página inicial com apresentação da marca Astra;
- Navegação entre páginas do site;
- Validação de e-mail, senha, CPF e idade;
- Simulação de autenticação de cliente;
- Cadastro de solicitações de serviços;
- Exibição de pedidos em tabela;
- Exclusão de solicitações;
- Interface visual consistente com tema tecnológico.

## Como executar

1. Abra a pasta `AV1`.
2. Inicie o arquivo `index.html` no navegador.
3. Navegue pelas páginas disponíveis:
   - `login.html`
   - `cadastro.html`
   - `trocar-senha.html`
   - `solicitacoes.html`

> Como o projeto é estático, não é necessário instalar dependências ou rodar um servidor back-end.

## Observações

- Os dados de login e solicitações são armazenados no navegador usando `localStorage`.
- O projeto foi pensado como uma demonstração front-end de desenvolvimento web.
- A identidade visual e os textos foram adaptados para uma empresa fictícia de tecnologia.
